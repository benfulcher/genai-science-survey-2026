How this was made: responses come from the event's Microsoft Forms survey, which was anonymous. Talk-proposal details (names, emails and titles) are left out, and one comment's contact details were removed. Claude read every free-text answer, split it into excerpts (each list item, or each sentence or run of sentences on one point) and coded each excerpt into a theme by hand. A comment can carry several themes, so theme counts add up to more than the number of comments. For this public version, each quote shows only the respondent's career stage. Excerpts that could identify someone (a named unit, a thesis topic, a distinctive research program) are withheld, and a few others are lightly edited in [square brackets] to blur the field. Respondent-level data is published without IDs, Schools, timestamps or free text, in shuffled order.
